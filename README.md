# Caesar Cipher

Encrypt and decrypt text with a classic letter shift (1–25). Runs entirely on your machine—no API keys.

## Run the web app

```powershell
cd c:\Users\emmak\Desktop\Content\CodingProjects\PortProjects\demos\caesar-cipher\web
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload --port 3011
```

Open http://localhost:3011

## Run the terminal reference

```powershell
cd c:\Users\emmak\Desktop\Content\CodingProjects\PortProjects\demos\caesar-cipher
python reference\caesar.py
```
