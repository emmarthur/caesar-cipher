About this app

A Caesar cipher replaces each letter with another letter shifted along the alphabet by your chosen key ({{ min_shift }}–{{ max_shift }}). It is a simple substitution cipher — fine for puzzles, not for real security.

How to use it

  • Type or paste text in Message, set the Key shift slider, then click Encrypt or Decrypt.
  • Only letters change; digits, spaces, and punctuation stay the same.
  • Decrypt with the same key you used to encrypt.
  • Use output ↓ copies the result back into the message field for chaining operations.
  • Copy result sends the output to your clipboard.
